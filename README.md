# CritiComrade

Web application for movie reviews — diploma thesis implementation (RA135/2018).

**Repository:** [github.com/laslo-uri/CritiComrade](https://github.com/laslo-uri/CritiComrade)

## Structure

| Directory | Stack | Run |
|-----------|-------|-----|
| [`backend/`](backend/) | Spring Boot 3, Maven, PostgreSQL | `./mvnw spring-boot:run` (from `backend/`) |
| [`frontend/`](frontend/) | Angular | `npm install && npm start` (from `frontend/`) |

## History

Merged from separate repos `CritiComrade-Backend` and `CritiComrade-Frontend` into a single monorepo.
